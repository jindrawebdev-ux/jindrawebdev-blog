= COMPLETE .htaccess FOR jindrawebdev.com =============================

Reference copy of the site's root .htaccess with every change applied.
This file is NOT deployed — .htaccess is edited by hand on the server,
because a bad deploy of it takes the whole site down with a 500 and
would also break the very deploy mechanism used to fix it.

Sections, in order:
  1. Original rewrite rules   (unchanged, yours)
  2. Blog article rule        (added — already live)
  3. Sensitive file blocking  (added — already live)
  4. Compression + caching    (added — the new part)

Order matters. The blog rule must sit BEFORE the generic "serve .php"
catch-all, or /blog/{slug} falls through to a 404.

=======================================================================

Options -MultiViews
RewriteEngine On

DirectoryIndex index.php index.html

# Redirect /index.html or /index.php to /
RewriteCond %{THE_REQUEST} \s/+index\.(html|php)[\s?] [NC]
RewriteRule ^index\.(html|php)$ / [R=301,L]

# Redirect .html URLs to clean URLs
# /about.html -> /about
RewriteCond %{THE_REQUEST} \s/+(.+?)\.html[\s?] [NC]
RewriteRule ^(.+?)\.html$ /$1 [R=301,L]

# Redirect .php URLs to clean URLs, except your form handler
# /about.php -> /about
RewriteCond %{THE_REQUEST} \s/+(.+?)\.php[\s?] [NC]
RewriteCond %{REQUEST_URI} !^/send-contact\.php$ [NC]
RewriteRule ^(.+?)\.php$ /$1 [R=301,L]

# Blog article pages: /blog/{slug} -> /article.php?slug={slug}
RewriteRule ^blog/([a-z0-9\-]+)/?$ /article.php?slug=$1 [L,QSA]

# Serve .php files when clean URLs are requested
# /about loads /about.php
RewriteCond %{REQUEST_FILENAME} !-d
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{DOCUMENT_ROOT}/$1.php -f
RewriteRule ^(.+)$ /$1.php [L]

# Fallback: serve .html files if still present
RewriteCond %{REQUEST_FILENAME} !-d
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{DOCUMENT_ROOT}/$1.html -f
RewriteRule ^(.+)$ /$1.html [L]

# ---- Block access to sensitive files ----
<FilesMatch "^(error_log|php_errors\.log|\.user\.ini|\.htaccess|\.htpasswd)$">
    <IfModule mod_authz_core.c>
        Require all denied
    </IfModule>
    <IfModule !mod_authz_core.c>
        Order allow,deny
        Deny from all
    </IfModule>
</FilesMatch>

# ---- Block backup/source files left in the web root ----
<FilesMatch "\.(bak|backup|old|orig|save|swp|sql|log|ini)$">
    <IfModule mod_authz_core.c>
        Require all denied
    </IfModule>
    <IfModule !mod_authz_core.c>
        Order allow,deny
        Deny from all
    </IfModule>
</FilesMatch>

# ---- Gzip compression ----
<IfModule mod_deflate.c>
    AddOutputFilterByType DEFLATE text/html text/plain text/xml text/css
    AddOutputFilterByType DEFLATE application/javascript application/x-javascript
    AddOutputFilterByType DEFLATE application/json application/xml
    AddOutputFilterByType DEFLATE image/svg+xml
</IfModule>

# ---- Browser caching ----
<IfModule mod_expires.c>
    ExpiresActive On
    ExpiresByType image/jpeg              "access plus 1 year"
    ExpiresByType image/png               "access plus 1 year"
    ExpiresByType image/webp              "access plus 1 year"
    ExpiresByType image/svg+xml           "access plus 1 year"
    ExpiresByType image/x-icon            "access plus 1 year"
    ExpiresByType video/mp4               "access plus 1 year"
    ExpiresByType text/css                "access plus 1 month"
    ExpiresByType application/javascript  "access plus 1 month"
    ExpiresByType font/woff2              "access plus 1 year"
    ExpiresByType text/html               "access plus 0 seconds"
</IfModule>
